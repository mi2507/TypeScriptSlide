# TypeScript Slides — Stories

Projeto desenvolvido como exercício prático durante o curso **TypeScript para Iniciantes**, da Origamid.

A aplicação implementa uma interface de slides no formato Stories, com navegação entre conteúdos e recursos de apresentação utilizando TypeScript e manipulação do DOM.

## 🎯 Objetivo

Praticar os fundamentos do TypeScript por meio da construção de uma interface interativa de slides, trabalhando com classes, métodos, eventos e controle de apresentação dos conteúdos.

## ✨ Funcionalidades

- Exibição de slides em uma interface inspirada no formato Stories.
- Navegação entre slides.
- Avanço e retorno entre os conteúdos.
- Reprodução automática com controle de tempo.
- Suporte à apresentação de imagens e vídeos.
- Manipulação de elementos HTML por meio do DOM.

## 🛠️ Tecnologias utilizadas

- **TypeScript** — tipagem estática e organização da lógica.
- **JavaScript** — execução do código no navegador após a compilação.
- **HTML5** — estrutura da aplicação.
- **CSS3** — estilização da interface.
- **DOM API** — manipulação dos elementos da página.
- **Git e GitHub** — versionamento do código.

## 📚 Conceitos praticados

Durante o desenvolvimento, foram praticados conceitos como:

- Classes e métodos em TypeScript.
- Tipagem de parâmetros e propriedades.
- Manipulação do DOM.
- Eventos e navegação entre slides.
- Temporizadores para controlar a apresentação.
- Organização do código em módulos.
- Compilação de TypeScript para JavaScript.

## ▶️ Como executar o projeto

### Pré-requisitos

- Node.js e npm instalados.
- TypeScript disponível no projeto ou instalado por meio do npm.
- Visual Studio Code com a extensão Live Server, ou outro servidor local para abrir a aplicação.

### Passos

1. Clone o repositório:

   ```bash
   git clone URL_DO_SEU_REPOSITORIO
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd NOME_DA_PASTA
   ```

3. Compile os arquivos TypeScript:

   ```bash
   npx tsc
   ```

4. Abra o arquivo `index.html` utilizando o Live Server.

> A execução depende da estrutura de arquivos e das configurações presentes no projeto. Caso o TypeScript não esteja instalado localmente, será necessário configurar essa dependência antes da compilação.
